## GitHub Pages Deploy
1. Create new repo (e.g. aizaz-payments)
2. Upload index.html to root
3. Settings > Pages > Source: Deploy from branch: main / root
4. Wait 1-2 min, your link: https://YOURUSERNAME.github.io/aizaz-payments/

## Custom Domain (optional)
- If you own zaman.publicvm.com or custom domain:
  - In repo Settings > Pages > Custom domain, enter domain
  - Add CNAME file with domain
  - Add DNS CNAME record pointing to YOURUSERNAME.github.io
